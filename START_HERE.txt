ماذا تريد أن تفعل الآن؟ اختر رقماً:

──────────────────────────────────────────────────────────────
1) أريد تشغيل التطبيق على حاسوبي
──────────────────────────────────────────────────────────────
   افتح المجلد:  01_Desktop_MoMoLink
   انقر مرتين على:  run_desktop.bat

   (أول مرة فقط: سيثبّت المكتبات — يحتاج إنترنت، دقيقة واحدة)


──────────────────────────────────────────────────────────────
2) أريد ملف EXE واحد جاهز (يعمل بدون بايثون)
──────────────────────────────────────────────────────────────
   الملف جاهز أصلاً هنا:
      01_Desktop_MoMoLink\dist\MoMoLinkDesktopPro.exe

   لتغيير الكود وإعادة البناء:
      01_Desktop_MoMoLink\build_exe.bat


──────────────────────────────────────────────────────────────
3) أريد تطبيق الهاتف (ملف APK)
──────────────────────────────────────────────────────────────
   لا يمكن بناؤه على ويندوز — يُبنى مجاناً على GitHub:

   1. افتح GitHub Desktop
   2. File ← Add local repository ← اختر مجلد MoMoLink-Ecosystem
   3. Create repository ← Publish / Push
   4. في موقع GitHub: تبويب Actions ← Build MoMoLink ← Run workflow
   5. بعد الانتهاء: حمّل MoMoLinkConnect-APK من Artifacts


──────────────────────────────────────────────────────────────
4) أريد التحكم بحاسوبي من الهاتف ونقل الملفات
──────────────────────────────────────────────────────────────
   افتح المجلد:  03_Remote_Control

   أ) نقل الملفات + الحافظة المشتركة:
      انقر مرتين على:  run_bridge.bat
      ثم امسح رمز QR بكاميرا الهاتف.

   ب) تحكم كامل بشاشة الحاسوب من الهاتف:
      انقر مرتين على:  enable_rdp.bat
      (وبعد الانتهاء: disable_rdp.bat)

   الشرط: الهاتف والحاسوب على نفس شبكة الـ Wi-Fi.
   التفاصيل: 03_Remote_Control\README_REMOTE.md


──────────────────────────────────────────────────────────────
5) أريد معرفة ما تم اختباره وما لم يُختبر
──────────────────────────────────────────────────────────────
   افتح ملف:  README.md   ← القسم 8 «الصدق الهندسي»


──────────────────────────────────────────────────────────────
6) بعد تغيير اسم المشروع (مهم إن استعملت GitHub Desktop)
──────────────────────────────────────────────────────────────
   مجلد المشروع صار:   Desktop\MoMoLink-Ecosystem

   إذا أظهر GitHub Desktop أن المستودع «مفقود»:
       File ← Add local repository ← اختر مجلد MoMoLink-Ecosystem
       (ثم احذف السطر القديم من القائمة: نقرة يمنى ← Remove)

   (اختياري) لتغيير اسم المستودع على موقع GitHub:
       Settings ← Rename repository ← MoMoLink-Ecosystem


──────────────────────────────────────────────────────────────
معلومة مهمة
──────────────────────────────────────────────────────────────
   • أداة scrcpy و adb مدمجتان داخل مجلد scrcpy — لا تثبّت شيئاً.
   • لا تظهر أي نافذة سوداء (Terminal) إطلاقاً.
   • الهاتف يحتاج: تفعيل «تصحيح أخطاء USB» من خيارات المطوّر.
