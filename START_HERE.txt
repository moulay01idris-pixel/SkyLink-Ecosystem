ماذا تريد أن تفعل الآن؟ اختر رقماً:

──────────────────────────────────────────────────────────────
1) أريد تشغيل التطبيق على حاسوبي
──────────────────────────────────────────────────────────────
   افتح المجلد:  01_Desktop_SkyLink
   انقر مرتين على:  run_desktop.bat

   (أول مرة فقط: سيثبّت المكتبات — يحتاج إنترنت، دقيقة واحدة)


──────────────────────────────────────────────────────────────
2) أريد ملف EXE واحد جاهز (يعمل بدون بايثون)
──────────────────────────────────────────────────────────────
   الملف جاهز أصلاً هنا:
      01_Desktop_SkyLink\dist\SkyLinkDesktopPro.exe

   لتغيير الكود وإعادة البناء:
      01_Desktop_SkyLink\build_exe.bat


──────────────────────────────────────────────────────────────
3) أريد تطبيق الهاتف (ملف APK)
──────────────────────────────────────────────────────────────
   لا يمكن بناؤه على ويندوز — يُبنى مجاناً على GitHub:

   1. افتح GitHub Desktop
   2. File ← Add local repository ← اختر مجلد SkyLink-Ecosystem
   3. Create repository ← Publish / Push
   4. في موقع GitHub: تبويب Actions ← Build SkyLink ← Run workflow
   5. بعد الانتهاء: حمّل SkyLinkConnect-APK من Artifacts


──────────────────────────────────────────────────────────────
4) أريد معرفة ما تم اختباره وما لم يُختبر
──────────────────────────────────────────────────────────────
   افتح ملف:  README.md   ← القسم 7 «الصدق الهندسي»


──────────────────────────────────────────────────────────────
معلومة مهمة
──────────────────────────────────────────────────────────────
   • أداة scrcpy و adb مدمجتان داخل مجلد scrcpy — لا تثبّت شيئاً.
   • لا تظهر أي نافذة سوداء (Terminal) إطلاقاً.
   • الهاتف يحتاج: تفعيل «تصحيح أخطاء USB» من خيارات المطوّر.
